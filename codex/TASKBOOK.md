# SSE-Mamba 工作站执行任务书

版本：2026-09-15。关联稿件：TGRS-2026-06389，SSE-Mamba: A Mamba Framework with Shallow Spatiotemporal Enhancement for Infrared Video Small Target Detection。

## 1. 执行范围与预算

为拒稿后重投准备证据、可复现实验和论文/回复草稿。保持现有 Ours(n) 框架及默认损失，主要工作是核验和复用已有消融、补缺失配置、重评已有权重、收缩论文主张。

默认完整训练任务为 13 个：

- E1–E3：1 个辅助模块组合、2 个局部邻域配置。
- E4–E9：6 个损失权重配置。
- R1–R4：完整模型和原 STF-3DConv 变体各追加 2 个种子。

13 是建立在旧结果有效、资源齐全前提下的计划数。已有等价任务通过核验后标为 reused 并免跑。训练失败后从兼容 checkpoint 续训不新增配置，但消耗的时间必须计入统计。不得为了凑齐数字把失败任务或短训结果标为正式结果。

本包的 JSON 是语义实验清单，其中 `change` 不是训练程序的真实参数名。必须先从项目代码解析为真实配置和实际命令，再运行。不要直接把 JSON 字段当作 CLI 参数。本包 TASKBOOK.md 为此次执行规范；如同时收到早期《审稿意见核查报告》，它只作风险背景，其中更大的实验矩阵不属于默认任务。

以下项目未纳入默认训练预算：修复无效旧实验后的补训、缺失基准重训、IRDST 的 E1、反向配对、第三数据集同域训练、纯 SSM 算子归因矩阵。若需追加，先写出原因、具体配置和新增成本，由用户决定范围。预算内可执行任务不需要逐项确认。

## 3. 步骤二：核验旧实验与锁定协议

### 3.1 可复用的历史实验

逐行定位下列原稿实验的证据，不要仅凭表中有数字就标为复现成功：

- 单帧 YOLOv8n、五帧直接堆叠基线。
- SSTE；SSTE+LFSS；SSTE+LFSS+SAAM 完整模型。
- STF→3DConv、STF w/o DCN、STF w/o DWConv。
- IFSS w/o STF；IFSS/LFSS w/o SFIScan；IFSS/LFSS 的 SS2D 替代。
- 浅层默认位置和深层 stride 8、16、双层位置。

至少重评完整模型和 STF-3DConv 的已有 checkpoint，先确认评估程序和原结果可对应。保存 checkpoint 摘要并检查完整加载；不能用 strict=False 隐藏模型定义与权重的缺失/多余参数。重评不同的原因要定位：数据划分、输入分辨率、NMS、指标实现、checkpoint 选择等；不要调测试集阈值来追平原稿。

仅有论文数字时可保留为 `paper_reported`；只有确认配置、训练来源和评估协议可比的结果才可纳入本次正式合并统计。旧权重存在但训练 provenance 缺失，也不能凭一次推理补出丢失的 seed。

### 3.2 两个高优先级实现检查

**A. 非交织扫描的输出恢复。**

对两路同长特征 `m[0:L]`、`s[0:L]`：

- 交织输入是 `[m0,s0,m1,s1,...]`，对应输出配对 `(2i,2i+1)`。
- 分块拼接输入是 `[m0,...,mL-1,s0,...,sL-1]`，对应输出配对 `(i,L+i)`。

检查 flatten/unflatten、转置、扫描方向恢复、反向路线和 pooling 的实际索引。写一个确定性的索引测试验证位置映射：以恒等映射暂替 SSM，main=[10,20,30]、supp=[1,2,3] 经两种扫描和各自正确恢复后都应得到 [5.5,11,16.5]；再用非方形特征图和多个 batch/channel 验证位置。不要要求两种经过真实因果 SSM 的数值输出相同。保留同样的两路特征与序列长度，才能把它解释为顺序对照。发现旧实现配错时保留问题证据，将相关结果标为 invalid；不要用修复后的评估代码直接包装旧错误训练权重为正确消融。

**B. STF-3DConv 的替换边界。**

以代码差异和模型结构确认：替换 STF 时是否也删除了 DCN、DWConv；IFSS、LFSS 中是否仍含 SSM；外围通道、检测头和训练流程是否一致。记录到 `implementation_audit.md`。

默认重复原稿实际的 STF-3DConv 变体，以比较两种 STF 设计。不要为了得到“更纯”的算子对照而静默改成另一网络，随后仍使用原稿 94.87% 作为它的基准。当前实验不能自动证明 SSM 算子独立贡献或全网络 CNN/Mamba 的差异。

### 3.3 锁定训练和评估规则

生成 `protocol_lock.json`，记录真实解析值。稿件报告的默认值仅用于核对：T=5、时间间隔=1、输入 640×640、100 epochs、batch=8、Adam、初始学习率 0.001、cosine 至 0.00001、loss=(7.5,0.5,1.5)、NMS IoU=0.7、候选置信度下限=0.001。若历史代码与稿件不同，先查明并记录，禁止凭此段直接改动历史设置。

锁定：数据划分、完整训练策略、初始化/预训练来源、增强（同一 clip 中几何增强应保持时序一致）、学习率调度、有效 batch、精度、checkpoint 选取、推理和评价版本。消融只改清单指定变量。结构不同无法共享完全相同张量初始化时保持相同初始化规则和可记录 seed；不能从完整模型训练好的权重短暂微调冒充独立消融。

checkpoint 选择沿用有效的训练侧验证规则。若无独立验证集，使用事先固定的最终 epoch 等规则，不使用测试集挑 checkpoint/seed/损失权重；不得悄悄改变历史划分再直接与旧值混表。

种子规则：

- `BASE_SEED` 取可追溯完整模型的历史 seed，E1–E9 使用该 seed。
- 保存完整模型与 STF-3DConv 各自的有效历史 seed；在看新结果前确定包含这两个值的公共三 seed 集合 COMMON_SEEDS。不足三个不同值时按 2027、3407、42、123、456 的顺序补入未出现的值，并写入锁文件。
- 对每个模型生成 MISSING_SEEDS，即 COMMON_SEEDS 中没有有效同协议历史结果的 seed。只训练缺失的 (model, seed) 组合。两模型各有一个有效历史结果时，无论它们原 seed 相同还是不同，都只需各补两次，共四次。
- 例如历史 seed 分别为 0 和 42，公共集合可为 [0,42,2027]：完整模型补 42/2027，3DConv 补 0/2027，最终三组都可配对。若同为 0，则两模型均补 2027/3407。已有更多有效结果时进一步减少新增运行。
- 如果历史 seed/协议无法追溯，不得猜值或把旧结果冒充第三个有效种子。提出预算差额和证据缺口；暂停依赖该基准的正式比较，继续资源核查、实现及其他可成立项目。

## 4. 步骤三：解析任务并做小规模正确性检查

读取 experiment_manifest.json，将每个 change 映射到实际模块和配置键。生成 `resolved_experiments.json`，每行包含真实配置文件、配置差异、seed、依赖、checkpoint、输出目录和实际启动命令。

准备的命令应能在本工作站直接运行，不能包含尚未解析的占位符；先核对 CLI 帮助或项目现有 launcher。对每项列出真实默认配置与变更配置的差异。

只做验证正确性所必要的小测试：

1. 受影响模块的前向尺寸/有限值和一次反向传播检查；E1 替换后检测头输入保持兼容。
2. E2/E3 仅改变 LFSS 补充分支的局部 DWConv kernel 及维持尺寸所需的 padding。固定层数 n、通道、stride、dilation、残差与其他卷积；1×1 不是删除分支。
3. 六种 loss 配置实际到达 loss 函数，系数正确；不得误改分类类别权重或优化器 weight decay。
4. 小样本数据检查：五帧来自同一序列、关键帧标注正确、取帧间隔可追溯、坐标从网络输入还原到原图正确。

smoke run 单独命名，只用于查错，不能计入正式指标。产出 `preflight_report.md`。对通过检查的任务立即推进；某个变体不通过只暂停该变体及其依赖项。

| 1 | R3 / R4 | 完整模型 / 原 STF-3DConv，各自第二个待补公共 seed | 至多 2 |

每个正式任务输出：完整解析配置、seed、代码 commit/补丁摘要、数据划分哈希、命令、stdout/stderr、训练日志、best/last checkpoint（按协议）、指标、实际耗时与设备记录。重启前检查 registry、进程和配置摘要，避免重复训练；仅在代码/配置/优化器/调度器状态兼容时 resume。不得把其他配置的 checkpoint 当成 resume。

每个 E/R 训练任务完成后，自动派生对应 `TEST_<ID>` 子任务：按已锁定的训练侧规则选择 checkpoint，在相同 DAUB 正式测试集与指标协议下完成评价。训练日志中的 val 指标不能充当 test 结果。状态依次由 trained 进入 evaluated、verified，只有验证通过的正式 test 指标才能入论文表。JSON 已列出这 13 个测试槽位；复用已有等价完整测试缓存时必须核对 checkpoint、数据和协议摘要。这些是推理任务，不增加训练预算。

关键结果若不支持原结论，保存全部预定结果并收缩表述，继续可执行的剩余最小任务。不要通过换 seed、挑测试片段或临时加模块追求更好数字。

## 6. 步骤五：无需新增训练的评估

为每个评估固定 checkpoint 选择，建立可复用逐帧预测缓存。至少保存 seq_id、frame_id、原图尺寸、原图坐标框、类别、置信度及模型/配置来源，并显式保留空预测帧。

将 P2/P3/P4 组合任务解析为逐模型子任务并记录各自依赖。某个非交织变体无效或强基线权重缺失时，只阻塞该行；其他模型照常评估，组合表最终标记部分完成，不借此省略缺口。

### P1. 固定五帧的时间间隔失配

优先比较同一 DAUB 来源的完整模型、原 STF-3DConv、已有强视频基线。固定 stride=1 训练权重，在 s∈{1,2,4} 下重新取帧和前向：`[i−4s,i−3s,i−2s,i−s,i]`。

用零起始帧索引，每个视频只使用 i≥16 的共同关键帧集合；短于 17 帧的序列不纳入该曲线并报告数量。三种间隔都在共同集合上评估，包括 s=1；不能拿原稿的全测试集值充当该曲线起点。禁止跨序列取帧。

完整覆盖为 3 模型×3 间隔=9 次评估，其中 s=1 也需重评或复用完全相同集合的缓存；不是新增 9 次训练。输出 AP50、AP50–95、样本数和相对 s=1 的百分点变化。称为 temporal sampling mismatch，不泛化为所有实际帧率变化。基线权重缺失时记录该行缺口，不自动训练新基线。

### P2. 尺寸和场景分组

在查看各组模型效果前，依据真实标注统计并固定分组。默认候选是原图框最大边长 d≤3 px、3<d≤7 px、d>7 px；先检查每组数量，再在不看模型效果的情况下决定是否合并稀少组。明确是标注框尺寸而非物理发光目标尺寸。

比较完整模型、STF-3DConv、有效的 IFSS 非交织变体。尺寸 AP 必须正确 ignore 其他尺寸的真值，并遵循同一 evaluator 的匹配规则；不能简单删掉非本组真值而把其正确检测计作误报。无可靠分组 AP 实现时先修正评估或明确暂缺，不产出误导性数字。场景分组依据序列元数据或可核验标注；不根据模型表现挑场景。不存在单像素/海天线场景就明确未覆盖。

输出各组样本数、AP50/AP50–95 和全帧误报指标（定义单位与阈值）；保留逐帧预测作为复算来源。

### P3. 一个第三数据集的冻结外部测试

先检查是否已有适配的视频数据，只选一个。可优先评估 NUDT-MIRSDT 或 IRSTD-UAV 的接入成本；下载和划分以官方资料和实际文件为准。数据缺失需要访问凭据时列明具体资源，继续其他任务。

选择和冻结第三数据集及其划分，不看多个候选的模型成绩后挑表现好的那个。完整模型、STF-3DConv、强基线均用同一源数据集（优先 DAUB）训练的固定权重。不得混入目标域训练/微调权重、使用目标域标签调阈值或挑 seed。

先核对目标域是否与源域共享视频、背景片段或派生素材，报告已知重合和无法确认部分；有重合的部分不能计为独立外部证据。使用官方评估划分，若官方只提供验证集，准确命名，不改称隐藏测试集。

若 mask 转框，固定连通域、坐标端点和框置信度规则；单像素 mask 应得到非零面积合法框。点标注不能自行膨胀为任意大小的真值框来计算 AP；优先使用官方 mask/框标注，或采用并说明合法的点检测协议。AP 使用固定解码/评价规则；工作点指标使用源域预定阈值，目标域最优 F1 只能另列为 oracle。

这项完成后称为“第三数据集冻结权重外部验证”。它不等于第三数据集同域训练基准；默认不增加训练，也不默认复现第三数据集原作者的完整方法。

### P4. 精度和运行成本

对完整模型与 STF-3DConv 至少补 AP50–95、同硬件延迟/吞吐、峰值显存。固定 batch、精度、输入五帧/分辨率、预处理/NMS 是否计时、warm-up 和计时轮数；GPU 计时前后同步。正式速度/显存测量安排在无竞争训练负载时进行，不能把资源争用造成的时差当成模型性能差异。

优先沿用可核验的原速度协议。若原协议缺失，预先固定统一的新协议并将新测值单列，不能与旧 FPS 无说明混合。检查 FLOPs 工具是否漏计 SSM/DCN；无法可靠计数则报告局限，不伪造精确总量。

## 7. 步骤六：汇总、论文和回复

所有正式指标建立长表 `metrics.csv`，至少有 experiment_id、model、dataset、split_hash、seed、checkpoint、protocol_id、metric_name、metric_value、unit、provenance。原稿值和本次重评值必须分别标注。

输出六类可复用表：

1. `stf_repeats`：完整模型/原 STF-3DConv 每次结果、均值、样本标准差（ddof=1）、差值与运行成本。单次数据不能给虚构的标准差。
2. `components`：SSTE 固定下 LFSS×SAAM 四组合，仅在补齐的 DAUB 上称为完整四组合。IRDST 若未补 E1，保持累加表并标注限制。
3. `scan_neighborhood`：有效旧扫描顺序结果及 kernel=1/3/5，附参数和计算量差异。
4. `loss_sensitivity`：默认+6 个单因素配置，完整报告，不用新最优权重替换主结果。
5. `temporal_robustness`、`size_scene_breakdown`：共同样本集合和分组定义可追溯。
6. `external_generalization`：第三数据集、来源域、固定 checkpoint 和目标域使用规则清楚。

表格同时输出 CSV 和 LaTeX；图使用 SVG/PDF 或高分辨率 PNG 等静态科研格式。AP 单位、百分数与百分点必须明确，不混用。图表由保存的结果生成，不手工填想要的数字。

与实验并行完成技术比较表和英文回复骨架；等证据确定后写结果段落。按 REVIEWER_ACCEPTANCE.md 逐条对应 R1.1–R2.4，回复包含：回应、具体修改、证据表/图、稿件位置、限制。未完成项保留 TODO，禁止使用“we conducted”冒充完成。

论文主线落在浅层高分辨率融合的受控证据和具体实现。默认删除或收缩以下主张：SSM 必不可少；交织本身首创；浅层在所有数据集贡献最大；SAAM 已被证明专门修复扫描畸变；邻接保证微小目标不丢失。STF 替代同时改动对齐/卷积时不能把全部增益归于 SSM。

SFIScan 理论只需半页与实现一致的两路/多帧序列定义及状态递推，说明最终配对输出的计算路径，不虚构性能定理。把 SAAM/DCN 的常规成分移入辅助实现说明。补 IRMamba、MOCID、ViViM、SAIST、IRSAM 技术比较，酌情用一段区分 LVNet；直接阅读一手论文核对结构，不能仅按名称分类。现有可引用资料见验收文件。

有源码时在独立修改副本或分支中生成修改稿和差异记录；没有源码时输出 `manuscript_revision_snippets.md`。编译能力不足时准确注明未编译。提交入口、对外邮件和期刊上传不在本次执行范围内。

## 8. 中断恢复、阻塞和完成标准

状态集合：pending / blocked / ready / running / trained / evaluated / verified / failed / invalid / superseded / reused / complete。只有通过验收且有产物的任务可设 complete；论文报告值不能直接跳到 complete。trained 只表示训练结束，不能替代 evaluated 或 verified。

任务标识至少由 ID、数据划分、seed、解析配置摘要和代码版本共同确定。每次启动先核对 registry 与输出目录。新增代码修复若改变实验定义，旧 run 标记 superseded/invalid 并说明，不覆盖。

发现问题时分级处理：

- 路径可从项目配置发现、普通参数映射、常规局部 bug：直接定位/修复，记录并验证。
- 某个数据/权重缺失、某个变体失败：只暂停相关任务，继续其余训练、评估和文字工作。
- 需额外完整训练超出默认预算、必须改变评价协议或实验定义：给出具体补救方案和额外成本，请用户选择；不悄悄扩大工作量。
- 科学结果不理想：按事实汇总并收缩结论，不把“提升不足”当作技术阻塞或追加试验的自动理由。
