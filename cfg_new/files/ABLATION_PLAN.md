# TRACE 消融实验方案 v2（论点 a 主导版）

> 配套代码：`spec_trans_ssm.py`（已通过 8 项冒烟测试）；载体：三个 yaml。
> 原 `phys_ss2d.py`（显式差分 + CFL 子步）**不作废**——它降级为 E4 离散化对决中的对照臂。

## 0. 三条论纲：每组实验只回答一个审稿问题

新颖性审计的结论是：单独的"物理输运"和单独的"SSM"都撞车，唯一可辩护的贡献在交集的三个硬结果上。消融矩阵不再按模块（M1–M6）组织，而是按论纲组织——每个实验存在的理由是堵住一个具体的审稿攻击：

| 论纲 | 内容 | 堵住的攻击 | 实验组 |
|---|---|---|---|
| **T-c 分离论证** | 对角 A（逐像素积累）原理上无法整合运动目标能量；输运 A 可沿轨迹实现匹配滤波式增益 | "这只是又一个时序模块" | E1 |
| **T-a 可并行子类** | 空间均匀+时变系数 ⇒ 傅里叶乘子 ⇒ 频域复对角选择性扫描：精确、无条件稳定（无 CFL）、log T 并行 | "空间结构化 A 破坏扫描，你这不是 SSM，是 ConvRNN 重包装" | E2, E3, E4 |
| **T-b 混合分解** | 全局输运走谱域扫描（可并行），局部残差走序贯半拉格朗日——伽利略分解从物理动机升级为**计算必然** | "M2+M3+M4 = GRFP 的 flow-warped gated ConvRNN" | E5, E6 |

**反模块堆叠纪律**：全部变体共享 `SpecTransSSM` 同一份代码路径，消融只改 yaml 第 5 行的 args。`mode='diag'` 就是对角 A 对照（同代码、系数置零），杜绝"对照组实现不同导致的不公平"质疑。

## 1. 全局实验控制（先于一切实验，违反任何一条则结果作废）

1. **锚点**：E0 = `yolov8s-anchor-p2.yaml` + NWD-CIoU + 关 Mosaic/MixUp + clip 内共享增强。所有 Δ 相对它报告，不许相对原版 YOLOv8。
2. **等参数**：所有时序变体调 `d_state` 使参数量差 ≤5%，表格必须带 Params/GFLOPs 列。
3. **1×1 读出（E1/E2 专用控制）**：分离论证期间 `out_proj` 严格 1×1、`gnet` 去掉 3×3 分支，保证跨像素信息**只能**经由转移算子 A 流动。否则"网络从读出卷积作弊"的解释无法排除，T-c 不成立。全模型实验可放开。
4. **训练协议**：T=8、逐帧全监督（keep='all'）、BPTT 直通、两阶段（E0 预训练 → 插时序块微调，零初始化=恒等已由测试 5 验证）。
5. **统计**：关键对比（E1、E2、E5 主行）3 seeds，报 mean±std；其余单 seed。
6. **指标**：Pd/Fa/ROC + mAP50/AP_tiny 双协议；效率表报训练 it/s、推理 FPS、流式峰值显存。

## 2. 实验矩阵

### E1 分离论证（T-c）——最优先，先于一切真实数据实验

**E1.0 合成玩具（3–5 天，决定项目生死）**
- 数据：高斯目标 σ∈{0.7,1.0,1.5}px 注入白噪声（+可选真实杂波底），SNR∈{1,1.5,2,3,4,6}，速度∈{0, 0.25, 0.5, 1, 2, 4} px/帧，直线+随机转向两种轨迹，各 500 序列。
- 变体（等参，1×1 读出）：E0 单帧 / `diag` / `spectral` / `local` / `hybrid`。
- 指标：Pd@Fa=10⁻⁴ vs 速度；有效积累帧数 N_eff=(SNR增益)² vs T∈{2,4,8,16}，叠加匹配滤波 √T 参考线。
- **预测**：diag 仅在速度≤0.5px/帧（目标不出 PSF）时有增益，速度≥1 时 ≈ 单帧；输运变体增益随 T 增长、随速度衰减缓慢。
- **go/no-go**：若 diag 在速度≥1px/帧桶上与输运变体差距 <1pt Pd → T-c 不成立，整个物理叙事失去必要性论证，回到审计报告的"回退为普通门控 ConvRNN 并诚实描述"选项。

**E1.1 真实数据速度分桶**
- NUDT-MIRSDT（SNR≤3 子集）+ MIST；按 GT 帧间位移分桶 {≤0.5, 0.5–1, 1–3, >3} px/帧报 Pd。
- 交付物：Fig. 分离曲线族（论文 Fig.4 的升级版：Pd–T 曲线按速度分桶展开）。

### E2 物理项开关（T-a，谱域块内部）

载体 `yolov8s-spectrans-p3.yaml`，只改第 5 层 args；数据集 NUDT-MIRSDT + MIST：

| ID | args 变化 | 含义 |
|---|---|---|
| E2.1 | `mode='diag'` | 仅衰减+门控 = 对角 A（Mamba 时序类比） |
| E2.2 | `'spectral', adv=T, diff=F, decay=T` | +对流 |
| E2.3 | `'spectral', adv=F, diff=T, decay=T` | +扩散（无对流的消融完整性行） |
| E2.4 | `'spectral', adv=T, diff=T, decay=T` | 完整 Fokker–Planck（LLᵀ 各向异性） |
| E2.5 | 同 E2.4 但代码中令 l21=0, l22=l11 | 各向同性对照（3 行代码开关，低优先级，按原 P5 处置：+0.5pt 即收，不达则砍） |

**预测**：对流是运动桶主增益来源；扩散的价值体现在 MIST 不规则运动子集（速度估计误差的鲁棒垫）；若 E2.3≈E2.1 且 E2.4≈E2.2，扩散项砍掉，主文只留对流+衰减——**宁可少一项物理，不可留一项装饰**（审计报告"物理 vs 比喻"攻击的直接回应）。

### E3 选择性开关（T-a：为什么要 selective）

| ID | 配置 | 类比 |
|---|---|---|
| E3.1 | `selective=True`（默认） | S6 式输入依赖 |
| E3.2 | `selective=False` | LTI 常系数 = ConvS5 类比 |
| E3.3 | v 由相位相关（phase correlation）经典估计给出，不学习（~30 行，可选） | 传统配准对照 |

数据集拆静/动：NUDT（静背景）vs IRDST/MIST（动背景）。**预测**：静背景 E3.1≈E3.2（selectivity 无用武之地），动背景 E3.1 显著胜出——这一对结果就是"selectivity 的价值在于动态背景下逐帧重估运动模型"这句话的证据，也是与 ConvS5 划清界限的实验。若动背景上 E3.2 也追平 → selective 宣称砍掉。

### E4 离散化对决（T-a：效率与稳定性表，"这真的是 SSM"的硬证据）

同一系数头，三种离散化 + 两种扫描：

| 臂 | 实现 |
|---|---|
| 谱域 ZOH | `SpectralTransport`（本模块） |
| 显式差分 + CFL 子步 | 你们既有的 `phys_ss2d.py` |
| 半拉格朗日 warp | `LocalTransport`（v 置为全局共享以对齐） |

测量：训练吞吐 it/s、峰值显存、100 帧滚动 max|H| 与 NaN 率（冒烟测试 3 的放大版）、整数/半像素平移重建误差（测试 2/2b 的协议化）、Pd/Fa 平价性；另测 `scan='parallel'` vs `'sequential'` 墙钟时间 @ T∈{8,16,32,64,128}（GPU 上应呈 log vs 线性分离）与流式显存 vs 序列长度（应为常数，测试 6 已验证等价性）。
**交付物**：一张表 + 两张小图，直接回应审计"训练吞吐灾难"与"CFL 数值稳定"两条致命风险——谱域路径把这两条风险从"缓解"变成"由构造消灭"（|a(k)|≤1 是参数化保证，不是训练技巧）。

### E5 全局/局部混合（T-b / M2）

| ID | mode | 回答 |
|---|---|---|
| E5.1 | `spectral`（仅全局） | 全局输运单独值多少 |
| E5.2 | `local`（仅局部，v_g 关闭） | 无参考系分解时局部路径在动背景上是否劣化 |
| E5.3 | `hybrid`（默认） | 完整分解 |
| E5.4 | `hybrid`, bg_ratio∈{0.25, 0.5, 0.75} | 通道预算划分 |

数据集拆静/动；**额外指标**：背景强边缘掩码内的 Fa（动背景虚警成片的量化，M2 动机声明的直接检验）。**预测**：静背景 E5.2≈E5.3（安全性证据）；动背景 E5.1 以极低成本修掉大部分背景漂移、E5.3 最好、E5.2 在强边缘 Fa 上劣化（必要性证据）。这一对就是原方案 M2 那一小节，但现在多了计算论证：E5.1 的那部分是可并行扫描的。

### E6 门控与并行性的互斥（M4 的诚实版）

| ID | gate | 并行性 |
|---|---|---|
| E6.1 | `none` | 并行 |
| E6.2 | `input`（u_t 与帧差代理新息） | 并行 |
| E6.3 | `innov`（完整逐步闭环：ŷ=C_p·H̃ → r → g，已实现于 local/hybrid） | 强制序贯 |

协议：闪烁噪声注入曲线（原 M4 招牌图协议不变：测试序列随机帧加点噪声，Fa vs 噪声强度）+ 吞吐列。**论文要正面写出的结论**：完整新息门与并行扫描数学上互斥（增益依赖演化状态 → 破坏扫描结合律），E6 量化"多少 Fa 换多少吞吐"——若 E6.2 拿到 E6.3 的 ≥80% 抗闪烁收益，主推 E6.2 并把互斥性作为一个 finding；这比假装没有这个矛盾诚实得多，也是审稿人抓不到的把柄。

### E7 插入位置与序列长度（沿用原方案，载体已备）

- 位置：P3-only（`-p3.yaml`）/ P2+P3（`-p2p3.yaml`）/ P2-only（改 p2p3 第 6 层为直连）。
- T∈{3,5,8,16} + 长度外推：训练 T=8，流式测整段序列（测试 6 已保证机制正确，此处测精度是否随长度退化）。

## 3. 优先级与 go/no-go 链

```
E1.0 玩具分离 (3-5天) ──不通过──► 回退 ConvRNN 叙事 / 转领域期刊
   │ 通过
   ▼
E2 + E4 (共用训练 run, 2周) ──物理项无增益──► 砍装饰项, 收窄宣称
   │ 通过
   ▼
E1.1 + E5 (静/动数据集, 2周) ──动背景不显著──► 砍 M2 宣称, 仅留谱域效率卖点
   │ 通过
   ▼
E3 + E6 + E7 (2-3周) ──► 外部对表 (DTUM/SSTNet/Tridos/LMAFormer/MOCID/MI-DETR)
```

原路线图的 P0（强化锚点）不变；原 P1–P3 被 E1/E2/E5 吸收；速度监督与 M6 跟踪按审计结论移出主线（数据集无 track-ID，谱域全局 v 可用相位相关伪 GT 做定性可视化，不做定量宣称）。

## 5. 诚实边界（写论文前自己先承认的事）

1. **谱域全局路径只覆盖平移**。仿射/单应不是平移不变算子、不是傅里叶乘子，不在可并行类内——全局旋转/缩放残差归局部路径处理。论文里写清楚这个类的边界，比被审稿人指出来强。
2. **局部路径仍是序贯的，且与 NowcastNet 半拉格朗日、GRFP warp 重叠**。delta 必须由 E4（无条件稳定 vs 他们没讨论）和 E5（与谱域全局的分工）的数据说话，不能靠叙事。
3. **周期边界**：FFT 隐含周期性，大位移下内容会环绕；reflect pad（默认 8px）缓解但非根治，pad 大小随 v_max·T 上界设置，E4 里报一行敏感性。
4. **代码状态**：单元级验证（CPU），未做大规模训练；ultralytics 集成需按 `register_trace_modules()` 文档给 `parse_model` 加两个 elif（与你们 phys_ss2d 的接法一致）；AMP 下 FFT 段已强制 fp32。
5. **E2.5（各向同性开关）与 E3.3（相位相关臂）需各 ~30 行代码**，已在矩阵中标注，未实现。
