## A. 恢复可核验的投稿版本

需要 `experiment_manifest.json`、`REVIEWER_ACCEPTANCE.md`，以及与完整模型、原 3D 变体逐一对应的训练来源：不可变源代码/补丁、完整配置、初始化、seed、选权规则和数据划分。投稿 tex/PDF/bib 用于映射原行与修改稿件；其缺失本身不阻塞可成立的实验。

如果这些材料证明两个模型各有一个有效同协议历史结果，则回到至多 13 次：9 个 E 任务加 4 次缺失 seed。公共种子按任务书规则从有效历史 seed 推导，不需另拟新种子。不能以当前 20 epoch 候选代替所需来源。

## B. 建立新的统一 DAUB 实验系列（建议的备用方案）

这不是复现旧 94.87% 行，而是保留旧值来源、单独报告新的实验系列。拟定的具体差异：

| 项目 | 已观测历史候选 | 新系列提案，待批准 |
|---|---|---|
| 完整/3D 网络 | fullsize 与 3D 除 STF 外还改变 neck | 使用已导出的 frame5/conv3d-TIMSSM 匹配图；scale=n；LFSS n=4；仅 STF 设计不同 |
| 初始化 | DAUB 已训练完整模型 | 相同随机初始化规则、可记录 seed，不加载 DAUB 已训练权重 |
| epochs | 20 | 100，所有变体相同 |
| optimizer / lr | auto / 0.0001 / 非 cosine | Adam，lr0=0.001，cosine，lrf=0.01 |
| batch / precision | 8 / FP32 | 物理 batch=8、nbs=64、稳态累计 8、有效 batch=64；FP32 |
| 输入 | T=5、8 通道；时间顺序反转 | T=5，640，8 通道 `[g_i-4,g_i-3,g_i-2,g_i-1,g_i,R_i,G_i,B_i]`，参考槽为关键帧 |
| 关键帧覆盖 | 4795 请求、4763 唯一帧 | 每个声明关键帧恰好一个 clip；序列开头复制最早帧作为因果补齐，P1 仅用 i>=16 的共同集合 |
| 数据和选权 | test 目录参与选 best | 保留现有 train/test 序列划分，固定最后第 100 epoch；不以 test 选 checkpoint/seed/系数 |
| 损失 | (7.5,0.5,1.5) | 默认相同；E4–E9 仅指定分量乘 0.5 或 2 |
| 评价 | 当前历史加载器 | 修正一帧一例索引、显式通道顺序；conf=0.001、NMS=0.7、max_det=300、原图坐标 AP50/AP50–95 |
| 种子 | 仅知道无效候选 seed=0 | 新系列预先声明 [0,2027,3407]，不称为已恢复历史种子；E1–E9 用新 BASE_SEED=0 |

以上刻意列明了会改变实验定义的输入顺序、覆盖和选权规则。增强配置须从确认的参考 args 完整导出并对 clip 一致性做 smoke；E1 的替换块及 SAAM 开关也必须显式实现和检查后才能 ready。当前 `resolved_experiments.json` 中命令为 null，尚不能当作可启动队列；配置层面的提案不等于已验收实现。

| 训练项 | 次数 | 与默认 13 的关系 |
|---|---:|---|
| 完整模型：3 个新种子 | 3 | 原 R1/R3 加缺失的新基准一次 |
| 原结构边界的 STF-3DConv：3 个新种子 | 3 | 原 R2/R4 加缺失的新基准一次 |
| E1–E9 | 9 | 原预算内配置 |
| 总计 | 15 | **增加 2 次完整训练** |

按本地 8982 个训练关键帧、batch=8、保留尾 batch 估算，每 epoch 为 ceil(8982/8)=1123 个 microbatch。100 epochs 每次约 112300 个；新增两次约 **224600 个 microbatch、1796400 次关键帧采样**。这是工作量估算，尚未测量新训练的 GPU 小时，不能用推理 FPS 换算训练时间。重试/续训耗时另记，100 epochs 不缩短。

15 次可补默认新增矩阵和两模型的三种子重复，但还不能保证完整四组件表：若 SSTE、SSTE+LFSS 两个旧行也不能复用，补齐二者还要 **+2 次，即 17 次合计**。旧扫描顺序、位置或单帧基线的修复补训需另列，不包含在 15 或 17 中；IRDST E1、第三数据集同域训练、DFAR 重训均未加入。
